{% load i18n %} {% comment %} One Cub's Scouting America registration standing as a badge. Pass `standing` (a Standing value string), and `required` when the pack is asking this Cub for a registration: nothing on file then reads as something the family owes rather than a bare statement of fact. A Cub who has graduated or withdrawn still shows their standing but is not being asked for anything. Hence the two colours for one standing. Owed is amber, the same as the "needs attention" alert at the top of the family page, because it is one of the items that alert is counting. Grey stays for the Cub nobody is asking, and is also what a Not started requirement wears -- an owed registration in grey was indistinguishable from a requirement nobody had got to yet, which is exactly how it was read in review. {% endcomment %} {% if standing == 'CURRENT' %} {% translate 'Current' %} {% elif standing == 'EXPIRING_SOON' %} {% translate 'Expiring Soon' %} {% elif standing == 'EXPIRED' %} {% translate 'Expired' %} {% elif required %} {% translate 'Required' %} {% else %} {% translate 'Not on file' %} {% endif %}
