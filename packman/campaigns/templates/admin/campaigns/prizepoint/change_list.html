{% blocktranslate %} Prize Points define the sales tiers used to calculate how many points a Scout earns. Each entry pairs a sales total ("earned at") with the number of points awarded once that total is reached. Scouts spend earned points to select prizes during a campaign's prize window. {% endblocktranslate %}

{% blocktranslate %} Sales above the highest configured tier are not capped. The rate of points per dollar between the two highest tiers is extrapolated forward: for every full increment of the "earned at" difference between those two tiers, another increment of the point difference is added on top of the highest tier's points. {% endblocktranslate %}

{% translate "Example, based on the two highest configured tiers" %}
{% translate "Configured tier" %} {% translate "Highest configured tier" %} {% translate "Extrapolated" %} {% translate "Extrapolated" %}
{% translate "Point value" %} 3 4 5 6
{% translate "Earned at" %} $550.00 $650.00 $750.00 $850.00

{% blocktranslate %} Here, the two highest configured tiers are 3 points at $550.00 and 4 points at $650.00: a difference of 1 point per $100.00. Each $100.00 sold beyond $650.00 earns one more point, so $750.00 earns 5 points and $850.00 earns 6 points, and so on. {% endblocktranslate %}
